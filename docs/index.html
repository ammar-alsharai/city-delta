      How this page is built

      Every morning a Databricks job pulls three public sources into a Delta Lake model, checks the data, and publishes it here.

      1. SourcesOfficiële bekendmakingen, NDW Melvin road works, Open-Meteo
      2. BronzeRaw XML, DATEX II and JSON, archived as received
      3. SilverParsed, typed and deduplicated with MERGE
      4. GoldBadges, daily activity and data health
      5. This pageExported as JSON by a GitHub Action

      Data checks

      Each check has an alert rule. When a value crosses it, the status changes from OK to warning or failure, and the problem shows up here the same morning.
